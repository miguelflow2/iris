Créer le service sur Render Blueprint + clés fraîches · aucune carte

  1. render.com › Get Started › connecte-toi avec GitHub (gratuit, pas de carte).
  2. Autorise Render à voir le dépôt miguelflow2/iris.
  3. New › Blueprint › choisis miguelflow2/iris. Render lit render.yaml et propose le service vela-relais.
  4. Il te demande de coller les clés (marquées « sync ») — des clés fraîches :
    • VELA_ANTHROPIC_KEY
    • VELA_OPENROUTER_KEY
    • VELA_SECRET (un secret long au hasard)
    • VELA_ELEVENLABS_KEY (facultatif)
  5. Apply. Render installe et démarre. Quand c'est vert, teste l'URL fournie (https://vela-relais-XXXX.onrender.com/sante) → doit répondre {ok, amont, voix}.

Pas de Blueprint ? New › Web Service › dépôt iris, puis à la main : Root Directory serveur · Build pip install -r requirements.txt · Start uvicorn relais:app --host 0.0.0.0 --port $PORT · Plan Free, puis ajoute les variables ci-dessus.

2

Pointer relais.velaglass.ca vers Render Cloudflare · nuage GRIS

  1. Dans Render : le service › Settings › Custom Domains › Add › relais.velaglass.ca. Render affiche une cible CNAME (ex. vela-relais-XXXX.onrender.com). Copie-la exactement.
  2. Dans Cloudflare (DNS de velaglass.ca) : ouvre l'enregistrement relais et remplace-le :
    • Type CNAME, cible = la valeur donnée par Render.
    • ⚠️ Nuage GRIS (DNS only), pas orange — pour que Render vérifie le domaine et émette son certificat.
    Render passe alors « Verified » puis « Certificate issued » (quelques minutes).

Coupe le tunnel du PC (il n'est plus la source du relais) — sur le PC, PowerShell :

Get-Process cloudflared -ErrorAction SilentlyContinue | Stop-Process -Force
Remove-Item "$HOME\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup\lancer-tunnel.vbs" -ErrorAction SilentlyContinue

L'app des clients pointe déjà vers relais.velaglass.ca : rien à changer dans l'app, le backend a juste déménagé.

3

Vérifier + garder le service éveillé ping gratuit UptimeRobot

Depuis ton téléphone / un autre réseau, ouvre :

https://relais.velaglass.ca/sante

Doit répondre {ok:true, ...} en HTTPS.

Garder éveillé. Le gratuit Render endort le service après 15 min sans trafic (1er appel suivant ~40 s). Crée un moniteur gratuit UptimeRobot (HTTP, sans carte) qui frappe https://relais.velaglass.ca/sante toutes les 5 min → il reste chaud, et tu es alerté si le brain tombe.

À savoir, franchement :

• 750 h/mois gratuites = assez pour UN service 24/7 (le relais). C'est pourquoi on ne met pas le serveur de licences ici — le relais répond déjà à /api/licence en repli.

• Disque éphémère : les compteurs de quota repartent de zéro à chaque redéploiement. Sans conséquence pour le pilote.

• Ça n'ouvre pas l'encaissement : recevoir l'argent reste soumis au KYC (pièce d'identité), indépendamment de l'hébergement du cerveau.
