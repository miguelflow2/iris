IRIS PAR VELA

Télécommande

Envoie une commande écrite à IRIS, sur ton ordinateur resté à la maison, par le relais VELA. IRIS l'exécute sur l'ordinateur avec ses outils habituels. Les courriels, textos et appels attendent toujours ton accord ici. Les autres actions sur l'ordinateur (dont les suppressions) suivent le réglage « Confirmation avant une commande » (IRIS › Réglages › Contrôle de l'ordinateur) : en mode « dangereuses », seules les commandes reconnues comme dangereuses te sont demandées ; avec « Jamais », rien n'est demandé.

Limites : l'ordinateur doit être allumé, connecté à Internet, avec la télécommande activée (IRIS › Mode dehors) ; le délai de réponse dépend de la commande et du réseau et n'est pas garanti ; rien ne s'exécute pendant qu'IRIS est verrouillée. Sans lunettes VELA présentes, les commandes écrites utilisent l'aperçu limité d'IRIS, puis sont refusées.

Connexion

Ce code n'est pas encore affiché dans l'application IRIS : il est écrit dans le fichier « telecommande-pairing » du dossier de données d'IRIS, sur l'ordinateur.

Non connecté

L'adresse, le courriel et le code sont retenus dans ce navigateur seulement.
