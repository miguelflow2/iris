Installation

Installer IRIS.

Un seul fichier, pour Windows 10 et 11 (64 bits). Ni Python, ni compte à créer : tout est dans l’installeur. Vérifiez seulement la configuration minimale ci-dessous. Comptez une dizaine de minutes, téléchargement compris.

Télécharger IRIS La configuration minimale

Avant de télécharger

La configuration qu’il vous faut.

IRIS est une application Windows qui tourne en continu sur votre ordinateur. Voici ce qu’on recommande — à confirmer : ce ne sont pas encore des chiffres mesurés sur banc d’essai, mais des repères honnêtes, donnés avant d’installer.

Ça marche

Le minimum recommandé

  • Windows 10 ou 11, en 64 bits.
  • Un processeur récent à 4 cœurs.
  • 8 Go de mémoire vive (RAM).
  • ~1 Go d’espace disque libre.
  • Un micro : celui du PC, des lunettes VELA ou d’un casque.

C’est confortable

Le recommandé

  • Windows 11, en 64 bits.
  • Un processeur récent à 6 cœurs ou plus.
  • 16 Go de mémoire vive (RAM).
  • Un disque SSD avec environ 2 Go libres.
  • Un micro de bonne qualité, pour une écoute plus sûre.

Recommandé, pas encore « testé ». Ces repères seront remplacés par des chiffres vérifiés dès qu’on aura mesuré IRIS sur plusieurs machines. En cas de doute, écrivez-nous à contact@velaglass.ca : on vous dira franchement si votre ordinateur convient.

Téléchargement

Choisissez votre système.

IRIS est publiée pour Windows. Mac et Linux suivront : le contrôle du PC et la connexion aux lunettes s’appuient d’abord sur Windows. On préfère le dire.

Windows

Disponible

Windows 10 ou 11, 64 bits. Le service d’IRIS est embarqué dans l’installeur.

Télécharger pour Windows

246 Mo · version 0.1.0 · IRIS-Setup.exe

Installeur non encore signé : Windows affichera un avertissement. La marche à suivre explique quoi faire (étape 2).

La marche à suivre

Quatre étapes, dans l’ordre.

  1. Télécharger le fichier

    Il s’appelle IRIS-Setup.exe et atterrit dans votre dossier Téléchargements.

    Télécharger pour Windows Windows 10 et 11, 64 bits · 246 Mo · version 0.1.0

  2. Lancer l’installation

    Double-cliquez sur le fichier. Gardez le dossier proposé si vous hésitez. IRIS se lance toute seule à la fin.

    Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur Informations complémentaires, puis Exécuter quand même. Ce message vient de ce que l’installeur n’est pas encore signé ; il ne dit rien sur le contenu.

  3. Répondre à l’assistant

    Cinq questions, toutes modifiables plus tard : votre prénom ; le courriel de votre achat et un mot de passe qui reste sur l’ordinateur ; vos consentements ; le micro ; le mot d’activation. Aucune clé d’IA à coller : l’accès viendra du service de VELA, en cours de déploiement.

  4. Dire votre première phrase

    À voix haute : « Dis-moi Iris, rappelle-moi dans dix minutes. » IRIS confirme et programme le rappel. Les demandes qui passent par les modèles en ligne arriveront dès que le service sera déployé.

Bon à savoir

Ça marche même sans lunettes.

IRIS tourne seule sur un PC Windows. Le micro de l’ordinateur suffit — il est même plus clair que celui d’un casque Bluetooth.

  • Le mot d’activation, les routines, les rappels et la mémoire fonctionnent dès l’installation, sur votre appareil.
  • La voix française locale (Piper) parle hors ligne, sans clé.
  • Les réponses des modèles d’IA en ligne arrivent quand le service se déploie Bientôt.
