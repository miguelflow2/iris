Installation

Installer IRIS.

Un seul fichier, pour Windows 10 et 11 (64 bits). Rien d’autre à préparer : ni Python, ni compte à créer. Comptez une dizaine de minutes, téléchargement compris.

La marche à suivre

Quatre étapes, dans l’ordre.

  1. Télécharger le fichier

    Il s’appelle IRIS-Setup-0.1.0.exe et atterrit dans votre dossier Téléchargements.

    Télécharger pour Windows Windows 10 et 11, 64 bits · 246 Mo · version 0.1.0

  2. Lancer l’installation

    Double-cliquez sur le fichier. Gardez le dossier proposé si vous hésitez. IRIS se lance toute seule à la fin.

    Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur Informations complémentaires, puis Exécuter quand même. Ce message vient de ce que l’installeur n’est pas encore signé ; il ne dit rien sur le contenu.

  3. Répondre à l’assistant

    Cinq questions, toutes modifiables plus tard : votre prénom ; le courriel de votre achat et un mot de passe qui reste sur l’ordinateur ; vos consentements ; le micro ; le mot d’activation. Aucune clé d’IA à coller : l’accès viendra du service de VELA, en cours de déploiement.

  4. Dire votre première phrase

    À voix haute : « Dis-moi Iris, rappelle-moi dans dix minutes. » IRIS confirme et programme le rappel. Les demandes qui passent par les modèles en ligne arriveront dès que le service sera déployé.

Bon à savoir

Ça marche même sans lunettes.

IRIS tourne seule sur un PC Windows. Le micro de l’ordinateur suffit — il est même plus clair que celui d’un casque Bluetooth.

  • Le mot d’activation, les routines, les rappels et la mémoire fonctionnent dès l’installation, sur votre appareil.
  • La voix française locale (Piper) parle hors ligne, sans clé.
  • Les réponses des modèles d’IA en ligne arrivent quand le service se déploie Bientôt.
