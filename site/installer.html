Installation

Installer IRIS, étape par étape.

Cette page est écrite pour quelqu’un qui n’a jamais installé ce genre de logiciel. Il y a un seul fichier à télécharger et rien d’autre à préparer : ni Python, ni Node, ni compte à créer. Comptez une dizaine de minutes, téléchargement compris.

Téléchargement

Choisissez votre système.

IRIS est publiée pour Windows. Les versions pour macOS et Linux sont en préparation : le service d’IRIS n’est empaqueté que pour Windows, et la connexion Bluetooth aux lunettes comme le contrôle de l’ordinateur s’appuient sur des interfaces propres à Windows. Nous préférons le dire plutôt que de laisser un bouton qui ne mène nulle part.

Windows

disponible

Windows 10 ou 11, en 64 bits. Rien d’autre à installer sur la machine : ni Python, ni Node, ni compte à créer. Le service d’IRIS est embarqué dans l’installeur.

Télécharger pour Windows

246 Mo · version 0.1.0 du 3 septembre 2026 · IRIS-Setup-0.1.0.exe

macOS

en préparation

Aucune version pour Mac n’existe aujourd’hui, et aucune date n’est promise. Laissez-nous votre courriel : vous serez prévenu le jour où elle sort, et pas pour autre chose.

Me prévenir

Avant de commencer

Windows 10 ou 11

En 64 bits. Les versions pour Mac et Linux ne sont pas publiées.

Environ 1 Go d’espace

L’installeur pèse environ 246 Mo et l’application installée environ 780 Mo.

Un micro

Celui de l’ordinateur suffit, et il est même préférable à celui d’un casque Bluetooth.

Une connexion Internet

Pour le téléchargement et pour les modèles en ligne. Une fois le modèle de reconnaissance vocale installé, l’écoute, elle, fonctionne hors ligne.

La marche à suivre

Cinq étapes, dans l’ordre.

  1. Télécharger le fichier d’installation

    Le fichier s’appelle IRIS-Setup-0.1.0.exe. Il atterrit normalement dans votre dossier Téléchargements.

    Télécharger IRIS pour Windows Windows 10 et 11, 64 bits · 246 Mo
    Version 0.1.0 du 3 septembre 2026

  2. Lancer l’installation

    Double-cliquez sur le fichier téléchargé. L’assistant vous laisse choisir le dossier d’installation ; si vous ne savez pas, gardez celui qui est proposé. IRIS crée un raccourci sur le bureau et dans le menu Démarrer, puis se lance toute seule à la fin.

    Si Windows affiche « Windows a protégé votre ordinateur » : cliquez sur Informations complémentaires, puis sur Exécuter quand même. Ce message apparaît parce que l’installeur n’est pas encore signé par un certificat d’éditeur ; il ne dit rien sur le contenu du fichier.

  3. Suivre l’assistant de démarrage

    Au premier lancement, IRIS pose cinq questions. Chacune se change plus tard dans les réglages, rien n’est définitif.

    1. Bienvenue

    Votre prénom, pour qu’IRIS sache comment vous appeler.

    2. Votre compte

    Le courriel de votre achat, et un mot de passe qui protège l’accès à votre ordinateur. Aucune clé de fournisseur d’IA à coller : l’accès aux modèles est fourni par VELA.

    Le mot de passe ne quitte jamais l’ordinateur et n’y est jamais écrit en clair. Sans abonnement, IRIS démarre au plan Gratuit, qui donne déjà des modèles d’IA. Si vous avez pris un abonnement, c’est la clé IRIS-… reçue par courriel qui l’active, dans l’écran « Abonnement » — les trois étapes.

    3. Consentements

    Vous décidez, type de donnée par type de donnée, ce qui a le droit de quitter l’ordinateur. Pour qu’un agent réponde, il faut au minimum autoriser le « texte de vos demandes ». Tout le reste peut rester fermé.

    4. Micro et sortie audio

    Choisissez par quel micro IRIS vous entend et par quel haut-parleur elle parle. Conseil : gardez le micro de l’ordinateur. Le micro « Hands-Free » d’un casque ou de lunettes Bluetooth est en qualité téléphone et se comprend beaucoup moins bien.

    5. Mot d’activation

    « Dis-moi Iris » par défaut ; vous pouvez le remplacer. C’est aussi ici que se télécharge le modèle de reconnaissance vocale hors ligne, 41 Mo, pour que votre voix ne quitte pas l’appareil.

  4. Dire votre première phrase

    Parlez normalement, à voix haute :

    « Dis-moi Iris, ouvre mon navigateur. »

    IRIS répond de vive voix et agit. Si elle a besoin d’une précision, elle vous pose la question et vous pouvez répondre directement, sans répéter le mot d’activation.

    Vous préférez taper ? Le fil de conversation est là pour ça. Raccourcis utiles : Ctrl + Maj + Espace pour parler, Ctrl + Maj + I pour afficher IRIS, Ctrl + Maj + M pour couper le micro.

  5. Faire le tour du propriétaire

    Deux endroits valent le détour tout de suite :

    • Confidentialité : le registre de transparence et son bouton « Vérifier ». C’est là que vous contrôlez ce qu’IRIS a capté et envoyé.
    • Abonnement : votre plan, votre quota du mois, et le champ où saisir une clé d’abonnement si vous en avez une.

    La voix française naturelle vient avec le plan Pro. Au plan Gratuit, IRIS parle avec une voix installée sur Windows ; installez une voix française dans les réglages de Windows si la voix par défaut est anglaise.

Si quelque chose cloche

IRIS ne réagit pas à mon mot d’activation

Vérifiez le micro choisi dans les réglages : s’il s’appelle « Hands-Free », passez au micro de l’ordinateur. Regardez aussi l’indicateur de niveau dans la barre du bas : s’il ne bouge pas quand vous parlez, Windows n’envoie rien à IRIS.

La voix est en anglais

C’est la voix Windows de repli. Installez une voix française dans Windows (Heure et langue › Voix), puis choisissez-la dans Paramètres › Voix — ou passez au plan Pro, qui apporte la voix naturelle en français.

IRIS dit qu’elle n’a pas le droit d’envoyer quelque chose

C’est la porte de consentement qui fait son travail. Ouvrez Confidentialité et activez le type de donnée concerné, ou vérifiez que le mode 100 % local n’est pas actif.

Le quota du mois est atteint

IRIS le dit et cesse d’envoyer : pas d’échec silencieux, pas de dépassement facturé. Vous pouvez attendre le mois suivant, où le compteur repart à zéro, ou passer à un plan supérieur.

Pour les développeurs

Compiler IRIS depuis les sources.

Ces commandes sont celles du dépôt, à lancer depuis sa racine. Prérequis : Windows 10 ou 11, Node 20 ou plus récent, et Python 3.11 ou plus récent (3.13 est la version testée).

Préparer l’environnement

# dépendances Python, dans un environnement virtuel local
cd backend
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements-dev.txt
cd ..

# dépendances de l'application
npm install

Développer

# Electron + Vite avec rechargement à chaud ; lance le backend depuis backend/.venv
npm run dev

# vérification des types TypeScript
npm run typecheck

# tests du backend
cd backend
.venv/Scripts/python -m pytest tests -q

Compiler

# compile electron/ et renderer/ dans out/
npm run build

# empaquette le service Python en exécutable autonome (PyInstaller)
# → backend/dist/iris-backend ; les tests et un autotest des bibliothèques
#   natives doivent passer, sinon la compilation s'arrête
npm run backend:build

# tout d'un coup : backend + installeur Windows
npm run dist:full

Où atterrit l’installeur : release/IRIS-Setup-0.1.0.exe, à la racine du dépôt (le numéro de version suit celui de package.json). Le dossier release/win-unpacked/ contient l’application décompressée, pratique pour essayer sans installer.

Rien à installer sur la machine cible

Le service Python est empaqueté dans l’installeur : la machine qui reçoit IRIS n’a besoin ni de Python, ni de Node, ni d’aucun environnement de développement. Windows 10 ou 11 en 64 bits suffit.

Clés et fichiers de configuration

La clé ElevenLabs se met dans un fichier .env : backend/.env en développement (partez de backend/.env.example), ou %APPDATA%\IRIS\iris-data\.env pour l’application installée. Elle peut aussi se saisir dans Paramètres › Voix, qui l’écrit dans ce même fichier. Aucune clé n’est jamais écrite dans le code.
